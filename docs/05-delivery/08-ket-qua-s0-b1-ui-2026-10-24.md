## Localhost và phần tiếp theo

Web production đang chạy tại [http://localhost:3000](http://localhost:3000), [Tìm trọ demo](http://localhost:3000/tim-tro?demo=true). API giữ tại [health](http://127.0.0.1:8000/api/v1/health), [Swagger](http://127.0.0.1:8000/docs); worker có sẵn tiếp tục chạy. Không seed lại hoặc sửa env. Log web: `.tmp/b1-ui-web.stdout.log` và `.tmp/b1-ui-web.stderr.log`.

Đối chiếu live: 88 tin public demo, stats 94 listing/84 đủ thống kê (scope backend khác nhau). Tin `01M5PBDSQ1DZ14Y9N79GF4P4X3`: 3.400.000 đ/tháng/phòng, 21m²; API trả gần trung vị +9,7%, N=13. Đây là dữ liệu demo, không phải đo chất lượng trích xuất.

Chạy lại production: dừng đúng tiến trình web đang giữ :3000 trước build, `cd apps/web; npm run build; npm run start`. API/worker dùng hướng dẫn trong [README web](../../apps/web/README.md). Không chạy dev và start cùng cổng/cùng `.next`.

Ngoài phạm vi: đăng nhập/khu nhóm, tài khoản/token, Lab/đánh giá, extension, market, free search/yêu thích/basis filter mới và dữ liệu ảnh. Dùng specification đã chốt khi bắt đầu các gói đó; không có nút giả dẫn người dùng vào màn chưa tồn tại.
