## Kết quả triển khai

- `/` lấy stats thật; minh họa tự tạo tách khỏi API và vẫn hiện khi kho rỗng/lỗi. Không gọi ID `l-01`/`l-10` lên backend.
- `/tim-tro` dùng API lọc/sort/page, tổng và `hidden_no_price`; 20 tin/trang, URL tiếng Việt, key mảng lặp, giá triệu chuyển sang đồng một lần. Filter/sort về trang đầu, chuyển trang giữ bộ lọc/dataset. Danh mục phường đọc tất cả trang không lọc, cùng dataset, không dùng market summary.
- `/tin/[id]` đọc listing/evidence và comparison. `is_demo` quyết định badge; không gọi mọi tin thật là nguồn extension. Link card/similar/quay lại và điều hướng giữ `demo`. Comparison 503/404 không biến cả tin thành 404. Metadata và page dùng chung request cache; listing 404 trả `notFound` và HTTP 404.
- HTTP timeout, lỗi chuẩn/request ID, lỗi mạng/JSON được phân biệt; mọi fetch `no-store`, không mock/file fallback. Nullable date/price, rent range/from/person, phí riêng, emoji/code point và text incomplete được bảo toàn. Loading danh sách, trạng thái đang mở card, comparison loading và retry có sẵn.
- Response DTO public có OpenAPI đầy đủ; client dùng `openapi-fetch` + type sinh bởi `openapi-typescript`, lệnh sinh lại không cần API/DB chạy. File sinh không sửa tay. Thêm `is_demo` vào envelope listings; không thay enum/ngưỡng/luật pipeline hay quyền.
- Tạo env local có secret ngẫu nhiên, không in bí mật; SQLite phát triển riêng, đường dẫn tuyệt đối. CLI seed đọc `SEED_PASSWORD` qua Settings/root `.env`, thiếu thì dừng. Sửa lỗi seed có sẵn: thời gian thay đổi làm key xung đột khi chạy lại; nay giữ bài/ngày cũ, không làm mới bài vào cửa sổ thống kê. Chạy lại tạo 0 bài, xử lý 0 job.
- Sửa hiệu ứng cũ đang che nội dung khi chưa cuộn: minh họa/biểu đồ có dữ liệu vẫn đọc được. Giữ palette và bố cục prototype; chưa chuyển visual Stitch.
