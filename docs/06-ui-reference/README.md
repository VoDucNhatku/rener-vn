# Tham chiếu giao diện ReNER

Đọc [kết luận và phạm vi đã đính chính](01-ket-luan-va-pham-vi.md) trước khi triển khai hoặc yêu cầu chỉnh giao diện.

- [Bộ HTML, ảnh, ZIP và manifest](../../design-references/rener-ui-2026-10-24/README.md).
- Chỉ desktop; giữ hero cuộn local.
- Không coi tài sản tham chiếu là code ứng dụng đã tích hợp.
- Không tạo lại các màn đã có hoặc coi bốn ảnh xuất lỗi là bốn màn chưa thiết kế.

Các luật dữ liệu/API hiện hành vẫn nằm ở `docs/02-data/`, `docs/03-system/` và schema; phần tham chiếu này không thay thế chúng.
